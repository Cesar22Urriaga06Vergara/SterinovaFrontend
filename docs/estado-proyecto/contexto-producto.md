# Contexto del producto

El frontend Sterinova es la interfaz web del ERP para los equipos Comercial, Logística, Planta y Calidad. Busca centralizar flujos de clientes, cotizaciones, órdenes de servicio y ciclos de esterilización.

Los documentos funcionales expresan objetivos y reglas deseadas. La disponibilidad efectiva de cada flujo depende de la implementación de la interfaz, la API y la configuración del entorno.
